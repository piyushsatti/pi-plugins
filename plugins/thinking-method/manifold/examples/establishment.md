# Establishment across modes — fictional example

This is authored illustration, not an execution receipt. Global placement is plugin
policy; the source meanings and scoped acceptance are unchanged. No folders, source
access or participant decisions described below have actually been created here.

## First contact

**User:** Manifold.

**Agent:** Manifold connects needs—whose desired conditions matter—requirements—what
must hold—and systems—how things are organized and work. Those connections reveal
unclear expectations, missing pieces and solutions that miss their intended need.
Your Manifold is global, with spaces for different areas of life or work. Establishing
a foundation takes focused time, possibly across sessions; then we build on it. It
is hands-on, not an unattended setup. What area would you like to establish, and
would you prefer to start from documents or an interview?

No cwd inspection, document search or space creation has happened at this point.

## A document round

**User:** Our neighborhood meal program. Start from the rota and the two meeting notes
I attached; you can save our progress in a new meal-program space.

**Agent:** I'll use those three documents for the first round and save a checkpoint
in your global meal-program space. The rota describes assignments. The notes report
that recipients need dependable meals and volunteers want predictable workloads.
Those are attributed accounts; direct recipient input is missing. A filled rota alone
does not establish actual delivery. What does “dependable” mean for the next service
period from the recipients' perspective?

The actual checkpoint would preserve the three source locators/revisions, differing
accounts, this limited connection, missing perspective and next question. It would
not invent a delivery threshold, copy the source corpus or declare the program ready.

## Switch to an interview

**User:** I can answer about coordination. I don't know what recipients would say.
Our biggest current issue is discovering uncovered shifts too late.

**Agent:** I'll retain recipient needs as unconfirmed. Your coordination account adds
an earlier-warning need. How much notice would let you respond usefully to an
uncovered shift?

The agent asks one question and waits. It does not invent the answer or repeat a full
introductory questionnaire. A new account can be saved as an attributed partial view.

## Return to discovery, then pause

**User:** The escalation note specifies that. Read this attached note, then pause.

**Agent:** The authorized source set now includes that note. It specifies a coordinator
notification condition and response responsibility; those are source requirements,
not yet proof of operation. I'll link them to the earlier-warning need, flag the
unverified delivery claim and preserve recipient uncertainty. Our next possible step
is to examine how notification and response work together. Progress is saved in the
global space; I'll stop here.

The next step is a recommendation, not an authorization to run it after the user leaves.
The prior checkpoint survives. No “onboarding complete” percentage is produced.

## Help and resume

**User, later from a software checkout:** Manifold help. In meal-program, the rota is
complete but people still miss meals. Why?

**Agent:** A complete rota establishes assignment coverage, if that is its criterion.
It does not establish that meals reached people. In this space, the connection between
assignment, execution and actual delivery still needs evidence. We can inspect a
specific missed delivery to find the broken handoff. No fresh establishment is needed.

The cwd has no effect on the selected global space. Help is read-only unless a space
update was authorized. The agent reads only this space and the evidence needed for
the question; it does not search unrelated spaces or infer recipient testimony.

If global storage is unavailable, the agent says which operation failed and offers
provisional help in chat. It never creates a project-local Manifold folder as a fallback. If the user
asks for `init` again, the agent offers to resume the existing space rather than reset it.
