# Short Manifold prompts

These are conversational prompts, not a claim that every host has matching slash
commands. Use the linked skill. Manifold state is global, organized into dedicated
spaces; the current repository never selects a space or authorizes discovery.

| Say | Entry point |
| --- | --- |
| “Manifold.” | [Init](skills/init/SKILL.md): brief introduction and how to proceed. |
| “Manifold init for household care.” | [Init](skills/init/SKILL.md): establish a global space. |
| “Start from these documents.” | [Init](skills/init/SKILL.md): agree scope, then one discovery round. |
| “Interview me about what matters here.” | [Init](skills/init/SKILL.md): one useful question at a time. |
| “Switch to discovery using this document.” | [Init](skills/init/SKILL.md): continue the same space with a source batch. |
| “Pause here and keep our place.” | [Init](skills/init/SKILL.md): checkpoint the selected space and stop. |
| “Continue my household-care space.” | [Init](skills/init/SKILL.md): resume its checkpoint without starting over. |
| “Manifold help. I am stuck on this.” | [Help](skills/help/SKILL.md): diagnose, then one useful next step. |
| “Frame this situation.” | [Orient](skills/orient/SKILL.md). |
| “Whose needs are represented or missing?” | [Needs](skills/needs/SKILL.md). |
| “What requirements would address these needs?” | [Requirements](skills/requirements/SKILL.md). |
| “How is this arrangement organized, and how does it work?” | [Arrangements](skills/arrangements/SKILL.md). |
| “Where does this model fail to line up?” | [Review](skills/review/SKILL.md). |
| “What do these results establish?” | [Results](skills/results/SKILL.md). |
| “What changes now, and what remains true?” | [Change](skills/change/SKILL.md). |

Documents and interviews can alternate. Initial establishment takes focused time,
sometimes across sessions; a partial foundation can be used and expanded. This is
manual, collaborative work, not an AFK setup or a mandatory seven-stage sequence.
