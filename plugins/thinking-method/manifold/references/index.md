# Reference route and provision standing

This bundle selects Manifold material from `Knowledge/standards/manifold`.
It is a working-tree snapshot, not a Manifold release. Exact document identities,
source and excerpt hashes, source page status, update metadata and packaged hashes
are in [source-manifest.json](source-manifest.json). Each excerpt carries a standing
notice. The [source strategy](../SOURCE-STRATEGY.md) explains selection and updates.

Read the owning text below, not just this routing summary. Mixed-standing documents
must be interpreted provision by provision. Historical open labels are not current
unresolved choices when a later scoped decision settles them.

of an unavailable source. Required operational definitions for these skills are bundled.
