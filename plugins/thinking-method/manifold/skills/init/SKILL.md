# Establish Manifold

Read [global spaces and establishment](../../references/establishment.md). For the
opening, read [purpose](../../references/source/standard/foundations/purpose-and-scope.md);
load deeper definitions only when the conversation needs them.

## Starter prompt

> Manifold init. Help me establish a space for this area of my life or work.

## Method

1. Recognize supplied intent: first contact, a named new space or resumption. Global
   Manifold never depends on a repository root. At first contact, give the short
   needs/requirements/systems introduction, purpose, time investment and hands-on,
   incremental expectation from the establishment guide. Do this briefly even when
   the user supplies a subject and mode immediately, then proceed with those choices
   instead of asking again. Skip repeated orientation when resuming.
2. Offer the next choice: establish a space, resume an existing one, or get help if
   stuck. For a new space, ask its area and whether to begin from documents or an
   interview, reusing anything already stated. Do not start reading sources or create
   state merely because the user said “Manifold.”
3. After the user's choice, use the selected mode for one bounded round. Discovery
   uses an agreed source set; interviewing asks one useful question at a time. They
   compose freely. Apply [orient](../orient/SKILL.md), [needs](../needs/SKILL.md) or
   another capability when needed, without presenting a mandatory seven-stage process.
4. Show the small model or understanding produced, attribution and uncertainty.
   Where saving is authorized, append and read back a checkpoint in the selected
   global space using the helper; preserve prior notes. Proposals stay proposals.
5. Offer the next useful step or pause. Resume from the existing checkpoint on later
   invocations. Establishing the foundation once does not mean it is complete forever.

## Output and stopping

First contact returns a concise explanation and a choice, then waits. A selected
round returns a useful partial picture, saved checkpoint when possible, and one next
step. Stop at that boundary. There is no AFK setup, automatic interview, exhaustive
readiness checklist or claim of adoption from silence.

If global storage or sources are unavailable, state the exact affected operation and
continue supported conversation in chat. Never substitute a project-local Manifold,
create a folder in cwd, silently migrate sources or claim an unsaved checkpoint exists.
The global application contract does not change Manifold's documented meanings.
